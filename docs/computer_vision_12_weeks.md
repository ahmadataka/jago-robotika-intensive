# Computer Vision for Kids

## Outline 12 Weeks

Kelas ini dirancang untuk siswa `upper elementary` dan `junior high` dengan pendekatan bertahap:

- mulai dari pengenalan gambar digital dan kamera
- lanjut ke pemrosesan gambar sederhana
- kemudian masuk ke konsep `computer vision`
- dan di akhir siswa membuat mini project visual yang interaktif

Fokus pembelajaran bukan pada teori matematika yang berat, tetapi pada:

- memahami bagaimana komputer "melihat"
- memproses gambar
- mengenali pola visual sederhana
- dan membangun project yang menarik dan mudah dipresentasikan

## Tools yang Cocok

Rekomendasi tools:

- `Python`
- `OpenCV`
- `Streamlit` atau notebook / script biasa untuk demo visual

Jika ingin lebih ringan untuk awal:

- mulai dari script Python + gambar statis
- baru ke webcam setelah siswa nyaman

## Week 1 - Intro to Computer Vision

Fokus:

- apa itu computer vision
- contoh penerapan di kehidupan nyata
- bagaimana komputer membaca gambar

Output:

- siswa memahami konsep dasar computer vision dan contoh penggunaannya

## Week 2 - Review Python for Vision Projects

Fokus:

- variable
- condition

- function
- review library dasar

Output:

- siswa siap menggunakan Python untuk project visual

## Week 3 - Intro to Images in Python

Fokus:

- membaca gambar

Output:

- mini app / script untuk membuka dan menampilkan gambar

## Week 4 - Image Editing Basics

Fokus:

- crop
- resize

- tool edit gambar sederhana

## Week 5 - Color and Filters

Fokus:

- grayscale
- blur
- brightness
- color channels

Output:

- filter gambar sederhana

## Week 6 - Drawing and Visual Annotation

Fokus:

- menggambar garis
- rectangle
- circle

Output:

- project memberi anotasi pada gambar

## Week 7 - Intro to Webcam Input

Fokus:

- membaca input kamera
- menampilkan video frame sederhana

Output:

- aplikasi webcam sederhana

## Week 8 - Motion and Color Detection

Fokus:

- deteksi warna sederhana

- threshold dan masking dasar

Output:

- project interaktif berbasis warna atau gerakan

## Week 9 - Face Detection

Fokus:

- pengenalan deteksi wajah
- memakai model siap pakai
- menandai wajah pada frame kamera

Output:

- app deteksi wajah sederhana

## Week 10 - Fun Interactive Vision Projects

Fokus:

- filter kamera
- deteksi objek warna tertentu
- hitung objek sederhana

Output:

- mini project vision yang lebih seru dan personal

## Week 11 - Final Project Build

Fokus:

- memilih ide project

- memperbaiki tampilan dan alur demo

- color tracker game

Output:

- final project hampir selesai

## Week 12 - Final Presentation and Showcase

Fokus:

- presentasi project

Output:

- final project computer vision
- presentasi karya di depan guru / orang tua / teman

## Kenapa Struktur Ini Cocok

- siswa tidak langsung dibebani AI atau model yang kompleks
- materi visual biasanya terasa lebih menarik dan cepat terlihat hasilnya
- project mudah dibuat bertahap dari gambar statis ke webcam
- hasil akhirnya punya efek `wow` yang kuat untuk presentasi

## Catatan Pengajaran

Supaya kelas tetap ramah untuk siswa:

- mulai dari `gambar statis` dulu, jangan langsung webcam
- gunakan model siap pakai untuk face detection
- jangan terlalu fokus pada teori matematika
- perbanyak demo visual dan mini challenge

## Deskripsi Singkat Kelas untuk Promosi Wali Siswa

`Computer Vision for Kids` adalah kelas project-based yang mengajak siswa belajar bagaimana komputer dapat "melihat" dan memahami gambar. Siswa akan mempelajari dasar-dasar pengolahan gambar, menggunakan kamera, membuat filter visual, hingga membangun project interaktif seperti deteksi wajah, pelacakan warna, dan aplikasi berbasis webcam.

Melalui kelas ini, siswa tidak hanya belajar coding, tetapi juga melatih logika, kreativitas, problem solving, dan kemampuan membuat project teknologi yang modern dan menarik. Di akhir program, siswa akan memiliki karya computer vision mereka sendiri yang dapat dipresentasikan sebagai hasil belajar nyata.
